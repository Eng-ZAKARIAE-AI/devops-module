# DevOps — Travaux pratiques et projets

Ce dépôt regroupe les travaux pratiques et projets réalisés dans le cadre du
module DevOps. Il est organisé pour accueillir plusieurs sujets liés au
développement logiciel, aux tests et aux pratiques DevOps.

**Responsable du module :** Prof. Ali Habchi, PhD

## Contenu du dépôt

| Dossier | Sujet | État |
| --- | --- | --- |
| [`testing/tp-2-testing/`](./testing/tp-2-testing/) | Tests unitaires et d’intégration en Python avec `pytest` | Disponible |
| [`devops/`](./devops/) | Espace prévu pour les projets et travaux pratiques DevOps | À compléter |

Le dépôt évoluera au fil des travaux : chaque projet peut avoir son propre
README, ses instructions d’installation et ses commandes de validation.

## Tests et validation

Pour consulter la présentation détaillée du TP de tests, voir le
[README du projet](./testing/tp-2-testing/readme.md). Pour exécuter ses tests,
utiliser les commandes suivantes depuis la racine du dépôt :

```bash
cd testing/tp-2-testing
python -m pip install -r requierments.txt
python -m pytest
```

Le rapport du TP est disponible dans
[`testing/tp-2-testing/rapport/tp2-rapport.pdf`](./testing/tp-2-testing/rapport/tp2-rapport.pdf).
